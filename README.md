# **Incompetent! Psych Engine**
![incompetent](https://github.com/user-attachments/assets/9621e3c9-2c7f-4150-90cc-d6fce8b2f030)

A fork of Psych Engine 0.7.3, inspired by [Doido Engine!](https://github.com/DoidoTeam/FNF-Doido-Engine)

**Incompetent! Psych engine**, is a fork that makes Psych engine easier for hard coding use, along with some new features and tweaks.

# **Features!**
- Compilation to HTML5
- New Events.
- Features ripped straight from V-Slice.
- Some bug fixes to base Psych 0.7.3
- Inbuilt camera movement on note hit. (Can be disabled from the options)
- Cleaned up Boyfriend Sprites!
- HUD and Ratings have been split off to their own classes, allowing for easier HUD Creation.
- Alot of Features from Psych 1.0.x Backported.

**This engine does NOT support the mod folder or LUA!**

# **How to compile!**

0. Install the source code.
1. Open a terminal in the source code folder and run the command: *haxelib install hmm*
2. After hmm is installed, run: *hmm install*
3. If you are prompted to choose a location for the libraries, run: *.haxelib* 
4. If everything has been installed correctly, use the command *lime test windows* or *lime test html5*, to compile the game to the specific platform.
5. If no issues are found, the engine should compile without any errors.
